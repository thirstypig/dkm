# DKM Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and deploy the five-page DKM site for Donyell Kennedy-McCullough at `https://dkm.pasadenaworks.com`, hidden from search engines, with a working Formspree inquiry form.

**Architecture:** Static Astro 7 site, no client framework. Design tokens and copy are lifted from the approved review draft `review/index.html`; content constants live in one data module. GitHub Actions builds and deploys to GitHub Pages under a custom subdomain; Formspree receives form posts.

**Tech Stack:** Astro 7, TypeScript, Vitest 4 (+ Astro Container API for component tests), `@fontsource/bebas-neue` `@fontsource/archivo` `@fontsource/newsreader` (all 5.3.0), GitHub Pages, Formspree, Google Cloud DNS.

**Spec:** `docs/superpowers/specs/2026-11-12-dkm-site-design.md` — read it first. Visual source of truth: `review/index.html` (copy, tokens, layout CSS).

## Global Constraints

- Node `>=22.12.0`; Astro `^7.2.9`; Vitest `^4.1.11` — match `~/Projects/pasadenaworks/package.json`.
- Dev/preview port **3200** (`--port 3200`), Vite `strictPort: true` for server and preview. Register the 3200–3209 block for DKM in `~/Projects/MASTER-PORTS.md` and run `~/Projects/sync-master-ports.sh`.
- `site: 'https://dkm.pasadenaworks.com'`. Repo `thirstypig/dkm`, **public** (matches siblings; free Pages requires it).
- **No pricing anywhere.** No `$`, "per week", "installment", "34,000", "2,000" in any built page.
- Title line exactly: `Former SVP, Artist & Talent Relations Strategy and Casting`. The string `NOT HR` must never appear.
- Every page: `<meta name="robots" content="noindex, nofollow">`. `public/robots.txt` = `User-agent: *` / `Disallow: /`. No `@astrojs/sitemap`.
- Social URLs exactly (YouTube without tracking params):
  - `https://www.instagram.com/donyellkennedymccullough/`
  - `https://www.threads.com/@donyellkennedymccullough`
  - `https://www.youtube.com/channel/UCKr3zXboSlu9wY_KjiIr4dA`
  - `https://www.linkedin.com/in/donyellkennedymccullough/`
- Tokens exactly as `:root` in `review/index.html` (paper `#FAF8F3`, ink `#111111`, text `#3B3B3B`, muted `#8A8780`, rule `#E4E0D6`, accent `#7A2E22`, paper-dark `#141312`).
- Copy is verbatim from `review/index.html`, American English. The yellow `.tbd` About sentence is **in** (owner: "all in"), rendered as normal text.
- Nav order: Services · Approach · About · Contact; logo text `DKM` links `/`.
- Photos only the five in `review/img/`; never other people, children, or third-party images.
- Contact is form-only (no mailto).

## Review Focus

1. **Formspree ID not yet supplied** — the form must show a visible "not connected yet" notice and a disabled submit, never a fake success. → Task 4 test `renders not-connected state when formspreeId is empty`.
2. **Formspree returns non-2xx or the network fails** — visitor sees the error message and their typed message is kept (form not reset). → Task 4 test `keeps input and shows error on failed submit`.
3. **Browser address autofill fills the honeypot** — honeypot must be named `_gotcha` with label `Leave this field empty` (never "Company"), else real inquiries are silently discarded (sibling-repo incident). → Task 4 test `honeypot label is not an autofill field name`.
4. **Phone visitor can't reach other pages** — the review draft's "Menu" was static; the real header needs a working disclosure menu. → Task 2 test `mobile menu button toggles nav with aria-expanded`.
5. **Long name overflows at 390px** — "Kennedy-McCullough" in the About H1 must wrap, no horizontal scroll. → Task 3 Step "verify no horizontal overflow at 390px".
